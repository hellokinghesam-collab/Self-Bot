# 🤖 سلف‌بات تلگرام (Telegram Userbot)

سلف‌بات (Userbot) امن، پلاگین‌محور و کامل برای تلگرام — ساخته‌شده با
[Telethon](https://docs.telethon.dev/). روی **اکانت شخصی خودت** اجرا می‌شود
(نه یک بات جدا از BotFather).

## ⚠️ نکات امنیتی و قانونی — حتماً بخوان

1. **`SESSION_STRING` = رمز عبور کامل اکانت تو.** هرکسی این رشته را داشته
   باشد، بدون نیاز به رمز عبور یا کد تایید، کامل به اکانتت دسترسی دارد.
   - هرگز آن را در گیت‌هاب، چت، اسکرین‌شات یا هر جای عمومی قرار نده.
   - فقط به‌عنوان **Environment Variable** در Railway وارد کن.
   - اگر فکر می‌کنی لو رفته: فوراً از تلگرام **Settings → Devices** آن سشن را
     Terminate کن و سشن جدید بساز.
2. **این ربات فقط برای مدیریت اکانت شخصی خودت طراحی شده** — نه برای اسپم
   گروه‌ها و نه برای آزار کاربران دیگر. تمام دستورات فقط از چت
   **Saved Messages** خودت قابل اجرا هستند؛ حتی اگر کسی دیگر پیامی با متن
   دستور بفرستد (در هر چتی)، پردازش نمی‌شود، چون شرط اول این است که فرستنده‌ی
   دستور خودِ همان اکانت لاگین‌شده باشد.
3. استفاده‌ی افراطی از API تلگرام (پیام انبوه، فوروارد بیش‌ازحد سریع، عملیات
   مدیریتی پشت‌سرهم) می‌تواند باعث محدود یا مسدود شدن اکانت شود. این پروژه
   برای همین منظور چند محدودکننده‌ی نرخ (Rate Limiter) داخلی دارد — آن‌ها را
   دور نزن.
4. مخزن گیت‌هاب را می‌توانی **public** کنی؛ هیچ فایل این پروژه حاوی مقدار
   حساس هاردکد‌شده نیست (`.gitignore` هم `.env`، فایل‌های `.session` و
   دیتابیس را نادیده می‌گیرد). فقط هرگز فایل `.env` واقعی یا خروجی
   `generate_session.py` را کامیت نکن.
5. **مدیریت گروه** فقط در گروه‌هایی کار می‌کند که خودت در آن‌ها واقعاً
   ادمین با دسترسی لازم هستی؛ ربات قبل از هر عملیات این را چک می‌کند.

| **ترجمه** | ترجمه‌ی دستی یا خودکارِ پیام‌های خصوصی دریافتی |

| **آنلاین‌ماندن** | حلقه‌ی keep-alive برای پایدار ماندن اتصال و وضعیت آنلاین |
| **افزونه‌پذیر** | افزودن پلاگین جدید فقط با یک فایل در `plugins/` |

## 🚀 دیپلوی سریع روی Railway (۵ دقیقه)

### گام ۱ — گرفتن API_ID و API_HASH

1. برو به [my.telegram.org](https://my.telegram.org) و با شماره تلفنت وارد شو.
2. **API Development Tools** → یک اپلیکیشن جدید بساز (هر اسم دلخواه).
3. مقادیر `api_id` و `api_hash` را یادداشت کن.

### گام ۲ — ساخت Session String (فقط روی سیستم شخصی خودت!)

```bash
git clone <آدرس ریپازیتوری خودت>
cd selfbot
pip install -r requirements.txt
python generate_session.py
```

- API_ID، API_HASH، شماره تلفن، کد تایید (و رمز دومرحله‌ای در صورت فعال بودن)
  را وارد کن.
- در انتها یک رشته‌ی طولانی چاپ می‌شود — همان `SESSION_STRING` است. آن را
  موقتاً در یک Password Manager کپی کن.

⚠️ این اسکریپت را **روی Railway اجرا نکن** — فقط یک‌بار، لوکال.

### گام ۳ — (اختیاری ولی توصیه‌شده) تست سریع پیکربندی

```bash
export API_ID=... API_HASH=... SESSION_STRING="..."
python healthcheck.py
```

اگر پیام `🎉 همه‌چیز آماده است` را دیدی، یعنی مطمئنی روی Railway هم کار می‌کند.

### گام ۴ — ساخت پروژه در Railway

1. تمام فایل‌های این پروژه را (بدون `.env`) به یک ریپازیتوری گیت‌هاب پوش کن.
2. در [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo**
   → ریپازیتوری‌ات را انتخاب کن.
3. Railway به‌طور خودکار `requirements.txt` و `Procfile` را تشخیص می‌دهد؛
   نیازی به تنظیم دستی build نیست.

### گام ۵ — تنظیم متغیرهای محیطی

در تب **Variables** سرویس، این‌ها را اضافه کن:

| متغیر | الزامی؟ | مقدار |
|---|---|---|
| `API_ID` | ✅ الزامی | از my.telegram.org |
| `API_HASH` | ✅ الزامی | از my.telegram.org |
| `SESSION_STRING` | ✅ الزامی | خروجی `generate_session.py` |
| `COMMAND_PREFIX` | اختیاری | پیش‌فرض `.` |
| `DB_PATH` | اختیاری | پیش‌فرض `data/selfbot.db` (به گام ۶ نگاه کن) |
| `KEEPALIVE_INTERVAL` | اختیاری | پیش‌فرض `60` (ثانیه) |
| `LOG_LEVEL` | اختیاری | پیش‌فرض `INFO` |
| `DEVICE_MODEL` | اختیاری | پیش‌فرض `SelfBot` |

### گام ۶ — اضافه کردن Volume (برای حفظ دیتابیس بین دیپلوی‌ها) 🔴 مهم

فایل‌سیستم Railway بین دیپلوی‌های جدید **پاک می‌شود** (ephemeral). بدون
Volume، با هر بار push کد جدید، لیست‌های دوست/دشمن، تنظیمات و آمار روزانه‌ات
از بین می‌رود. برای جلوگیری:

1. در صفحه‌ی سرویس، تب **Settings → Volumes** (یا دکمه‌ی «+ Add Volume»).
2. یک Volume بساز و Mount Path را روی `/app/data` بگذار.
3. مطمئن شو `DB_PATH` روی مقدار پیش‌فرض `data/selfbot.db` مانده (که داخل
   همین پوشه‌ی mount‌شده قرار می‌گیرد).

### گام ۷ — Deploy و تست

1. روی **Deploy** بزن (یا اگر خودکار است، صبر کن تا Deploy تمام شود).
2. در تب **Logs**، دنبال این خط بگرد:
   ```
   سلف‌بات آماده و در حال اجراست. منتظر دستورات در Saved Messages...
   ```
3. برو به **Saved Messages** خودت در تلگرام و بنویس:
   ```
   .ping
   ```
   اگر پاسخ `🏓 Pong!` گرفتی، همه‌چیز درست کار می‌کند 🎉

## 📖 لیست کامل دستورات

همه‌ی دستورات فقط از **Saved Messages** قابل اجرا هستند.

### پایه
| دستور | توضیح |
|---|---|
| `.ping` | تست سرعت پاسخ‌گویی |
| `.bold متن` | ارسال به‌صورت بولد |
| `.italic متن` | ارسال به‌صورت ایتالیک |
| `.code متن` | ارسال به‌صورت کد (monospace) |
| `.del` | حذف پیام دستور (و پیام ریپلای‌شده در صورت وجود) |
| `.id` | نمایش آیدی چت/فرستنده/پیام |
| `.help` | نمایش راهنمای کامل داخل تلگرام |

### لیست‌ها (دوست / دشمن / دلخواه)
| دستور | توضیح |
|---|---|
| `.addfriend` (با ریپلای) | افزودن به لیست دوستان |
| `.addenemy` (با ریپلای) | افزودن به لیست دشمنان |
| `.add <لیست>` (با ریپلای) | افزودن به لیست دلخواه/سلیقه‌ای |
| `.remove <لیست>` (با ریپلای) | حذف از یک لیست |
| `.list <لیست>` | نمایش اعضای یک لیست |
| `.lists` | نمایش تمام لیست‌های موجود با تعداد اعضا |
| `.clearlist <لیست>` | پاکسازی کامل یک لیست |

### پاسخ خودکار
| دستور | توضیح |
|---|---|
| `.autoreply on` / `.autoreply off` | فعال/غیرفعال کردن پاسخ خودکار |
| `.setreply <لیست> <متن>` | تنظیم پاسخ خودکار برای اعضای یک لیست |
| `.unsetreply <لیست>` | حذف پاسخ خودکار یک لیست |

مثال:
```
.setreply enemy فعلاً در دسترس نیستم.
.autoreply on
```

### زمان‌بندی
| دستور | توضیح |
|---|---|
| `.schedule <دقیقه> <متن>` | ارسال خودکار متن در همین چت بعد از N دقیقه |
| `.scheduled` | نمایش پیام‌های زمان‌بندی‌شده‌ی در انتظار |
| `.unschedule <id>` | لغو یک پیام زمان‌بندی‌شده |

### فوروارد خودکار
| دستور | توضیح |
|---|---|
| `.fwdadd <source_id> <dest_id>` | ثبت قانون فوروارد از چت source به chat dest |
| `.fwdremove <source_id> <dest_id>` | حذف یک قانون فوروارد |
| `.fwdlist` | نمایش تمام قوانین فوروارد فعال |

برای پیدا کردن آیدی یک چت/گروه: پیامی از آن چت را به Saved Messages فوروارد
کن و روی همان پیام فوروارد‌شده دستور `.id` را بزن.

⚠️ محدودیت ایمنی: حداکثر ۱۰ فوروارد در هر ۳۰ ثانیه.

### فایل
| دستور | توضیح |
|---|---|
| `.save` (با ریپلای) | دانلود فایل/عکس/ویدیو روی سرور (پوشه‌ی `downloads/`) |
| `.upload <نام فایل>` | آپلود فایلی که قبلاً در `downloads/` ذخیره شده |
| `.storage` | نمایش حجم اشغال‌شده توسط فایل‌های دانلودشده |
| `.clearstorage` | پاک کردن همه‌ی فایل‌های دانلودشده |

⚠️ حداکثر حجم فایل قابل دانلود ۵۰۰ مگابایت؛ مسیر آپلود همیشه محدود به
`downloads/` می‌ماند (جلوگیری از Path Traversal).

### مدیریت گروه (فقط گروه‌هایی که خودت ادمین هستی)
| دستور | توضیح |
|---|---|
| `.gkick <group_id> <user_id>` | اخراج عضو از گروه |
| `.gban <group_id> <user_id>` | بن کامل عضو |
| `.gunban <group_id> <user_id>` | رفع بن |
| `.gmute <group_id> <user_id> <دقیقه>` | سکوت موقت عضو |
| `.gunmute <group_id> <user_id>` | رفع سکوت |
| `.ginfo <group_id>` | اطلاعات پایه گروه (عنوان، تعداد اعضا) |
| `.gadmins <group_id>` | لیست ادمین‌های گروه |

⚠️ قبل از هر عملیات، ربات بررسی می‌کند خودت واقعاً در آن گروه دسترسی ادمین
با مجوز مدیریت اعضا داری. حداکثر ۵ عملیات مدیریتی در هر ۶۰ ثانیه مجاز است.

### متفرقه
| دستور | توضیح |
|---|---|
| `.purge <تعداد>` | حذف N پیام آخر **خودت** در همین چت (سقف ۲۰۰) |
| `.edit <متن>` (با ریپلای روی پیام خودت) | ویرایش پیام قبلی |
| `.calc <عبارت>` | محاسبه‌گر امن (بدون eval/exec) |
| `.afk [دلیل]` | فعال کردن حالت AFK با پاسخ خودکار |
| `.unafk` | خاموش کردن حالت AFK |
| `.pin` / `.unpin` (با ریپلای) | پین/برداشتن پین پیام |

### ترجمه
| دستور | توضیح |
|---|---|
| `.tr <زبان> <متن>` | ترجمه‌ی متن داده‌شده |
| `.tr <زبان>` (با ریپلای) | ترجمه‌ی پیام ریپلای‌شده |
| `.autotr on <زبان>` | فعال کردن ترجمه‌ی خودکار پیام‌های خصوصی دریافتی |
| `.autotr off` | غیرفعال کردن ترجمه‌ی خودکار |

کدهای زبان رایج: `fa` فارسی، `en` انگلیسی، `ar` عربی، `tr` ترکی، `de` آلمانی،
`fr` فرانسوی، `es` اسپانیایی، `ru` روسی.

مثال:
```
.tr en سلام، حالت چطوره؟
.autotr on fa
```

⚠️ ترجمه از سرویس رایگان/غیررسمی گوگل (از طریق کتابخانه‌ی `deep-translator`)
استفاده می‌کند؛ در موارد نادر ممکن است موقتاً با خطا مواجه شود — پلاگین این
خطا را می‌گیرد و کرش نمی‌کند.

### آمار روزانه
| دستور | توضیح |
|---|---|
| `.stats` | آمار امروز: پیام ارسالی/دریافتی، دستورات اجراشده، چت‌های فعال |
| `.statsweek` | خلاصه‌ی جدولی ۷ روز اخیر |

هیچ متن پیامی ذخیره نمی‌شود؛ فقط شمارنده‌های عددی در دیتابیس محلی خودت.

### سیستم
| دستور | توضیح |
|---|---|
| `.status` | وضعیت کلی: آپ‌تایم، آخرین اتصال موفق، پلاگین‌ها، تعداد لیست‌ها |
| `.plugins` | نمایش پلاگین‌های بارگذاری‌شده |
| `.reload` | بارگذاری مجدد همه‌ی پلاگین‌ها بدون ری‌استارت کامل |

#### درباره‌ی «انقضا»ی سلف‌بات
تلگرام تاریخ انقضای ثابتی برای Session String اعلام نمی‌کند. سشن تا وقتی
معتبر است که خودت آن را از **Settings → Devices** حذف نکرده باشی، یا تلگرام
به‌دلیل بی‌فعالیتی طولانی (معمولاً چند ماه) یا رفتار مشکوک آن را باطل نکرده
باشد. به همین دلیل `.status` به‌جای «تاریخ انقضا»، آپ‌تایم و زمان آخرین
اتصال موفق را نشان می‌دهد؛ حلقه‌ی keep-alive هر ۶۰ ثانیه (قابل تنظیم با
`KEEPALIVE_INTERVAL`) این زمان را به‌روزرسانی می‌کند و اکانت را آنلاین نگه
می‌دارد.

## 🧩 ساخت پلاگین (افزونه) جدید

هر پلاگین یک فایل در `plugins/` است با تابع `async def register(client):`:

```python
# plugins/hello.py
from telethon import events
from config import COMMAND_PREFIX
from security import is_authorized

PREFIX = COMMAND_PREFIX

async def register(client):
    @client.on(events.NewMessage(pattern=rf"^\{PREFIX}hello$"))
    async def hello_handler(event):
        if not await is_authorized(event):
            return
        await event.edit("سلام! 👋")
```

🔴 **نکته‌ی حیاتی:** همیشه اولین خط داخل هندلر باید
`if not await is_authorized(event): return` باشد — این تنها راهی است که
تضمین می‌کند دستور فقط از Saved Messages خودت قابل اجراست.

بعد از افزودن فایل، با دستور `.reload` (یا ری‌استارت سرویس) پلاگین جدید فعال
می‌شود.

| در لاگ Railway نوشته «متغیر محیطی الزامی ... تنظیم نشده» | همان متغیر را در تب Variables اضافه کن |
| «SESSION_STRING نامعتبر است یا منقضی شده» | با `python healthcheck.py` (لوکال) بررسی کن؛ اگر نامعتبر بود، `generate_session.py` را دوباره اجرا کن و مقدار جدید را در Railway بگذار |
| بعد از هر دیپلوی، لیست‌ها/آمار پاک می‌شود | Volume را طبق [گام ۶](#گام-۶--اضافه-کردن-volume-برای-حفظ-دیتابیس-بین-دیپلویها--مهم) اضافه کن |
| `.tr` خطا می‌دهد | کد زبان را چک کن (مثلاً `en` نه `english`)؛ گاهی سرویس رایگان گوگل موقتاً کند/ناموفق است — دوباره امتحان کن |
| مدیریت گروه با «تو در این گروه ادمین نیستی» رد می‌شود | باید در آن گروه واقعاً نقش ادمین با دسترسی «مدیریت اعضا» داشته باشی |
| ربات به نظر آفلاین می‌آید | مقدار `KEEPALIVE_INTERVAL` را کاهش بده (مثلاً به `30`) و لاگ‌ها را برای خطای اتصال چک کن |

## 💻 اجرای محلی (برای تست)

```bash
pip install -r requirements.txt
cp .env.example .env
# مقادیر .env را با ادیتور دلخواه پر کن (API_ID, API_HASH, SESSION_STRING)
```

لینوکس/مک:
```bash
export $(grep -v '^#' .env | xargs)
python healthcheck.py   # بررسی سریع قبل از اجرای کامل
python main.py
```

ویندوز (PowerShell):
```powershell
Get-Content .env | ForEach-Object {
  if ($_ -match '^\s*([^#=]+)=(.*)$') { [System.Environment]::SetEnvironmentVariable($matches[1], $matches[2]) }
}
python healthcheck.py
python main.py
```
